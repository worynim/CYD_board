## v1.1.0 (2026-08-24)

### 🔬 진단·실험
- **티어링 제거 시도 3단계 — 실패 확정, 직접 디코드 모드가 이 보드의 최종 형태**:
  1. **풀프레임 저장소 체이스**: 완성 프레임을 RAM에 저장해 스캔과 무경합으로 기입하는 설계. 메모리 실측으로 불가 확정 — 힙 최대 연속 블록 107KB 세그먼트 벽(.bss 48KB를 힙으로 옮겨도 불변), 부팅 직후 대량 할당 시 Wi-Fi 접속 자체 실패(잔여 ~98KB), Wi-Fi 접속 후 총량 부족(149 < 154KB). 하드웨어에서 실행되지 못함.
  2. **밴드 체이스(블록 게이트)**: JPEGDEC 콜백의 MCU 블록(16×16=512B)을 144슬롯 풀(~72KB)에 쌓고 `getScanLine()` 래스터 헤드가 지나간 블록만 방출. 풀 활성 + `[STAT] lag=0`으로 기구는 설계대로 동작했으나(rt·rend_fps 열화 없음, push 17.3→19.7ms) **티어링은 헤드 방향 반전(`TEAR_SYNC_MAP_FLIP`) 0/1 양쪽 모두 심함** → GSCAN은 주기(~16.7ms)는 맞지만 원점/위상이 논리 좌표와 불일치. 공개 API로 스캔 위상 동기화는 이 보드+LGFX 조합에서 불가 판정.
- **rx/render JPEG 버퍼(48KB) .bss→힙 이동**: 최대 연속 블록엔 영향 없었으나 전역 115.9→66.4KB로 BSS 여유 확보 — 독립 이득으로 유지.

### 📌 업그레이드 노트 (필독)
- **펌웨어 재업로드 필요**: `RENDER_TEAR_SYNC 0`(직접 디코드 모드 복귀) 빌드를 Arduino IDE에서 재업로드할 것. 체이스 코드는 스위치 뒤에 보존됨(재검증용).

## v1.0.0 (2026-08-24)

### 🐛 수정
- **레거시 기본값·주석 불일치 정리**: GUI 슬라이더 라벨이 실제 기본값(품질 60 / FPS 18)과 어긋나 있던 것과, `[FIX #12]` 계열 주석이 옛 상한 16fps를 인용하던 것을 현재 동작(CAP=30)에 맞게 수정. 동작 변경 없음.

### ✨ 추가·개선
- **최신 프레임 우선 소비 [LATEST-WINS]** (`streamer_gui.py` `_stream_worker`): 전송 큐에 프레임이 밀려 있으면 낡은 것을 폐기하고 최신 1장만 보낸다. 발신률이 디바이스 렌더 한계(~18fps)를 넘어도 호스트 측에는 낡은 프레임이 쌓이지 않음.
- **전송률 실험 상한**: `DEVICE_RENDER_FPS_CAP` 16 → **30**. 디바이스 물리 한계(rt≈54ms ≈ ~18fps) 실험을 위해 슬라이더 최대까지 허용. 초과분은 폐기가 아니라 최신 프레임 교체로 처리됨(`pendingCommit`+latest-wins).
- **기본값 변경**: JPEG 품질 45 → **60**, 목표 FPS 16 → **18** (AP 다운링크 적체 완화 + 화질 개선의 균형점).

### 🔬 진단·실험
- **수초 지연 원인 확정 — AP 다운링크 큐 적체(bufferbloat)**: `ping -i 0.3 <CYD IP>` 3단계 실험으로 확인. 스트리밍 중 RTT가 단조 증가(5→1558ms), 정지 후 ~3초에 걸쳐 감쇠(2117→6ms)하며 디바이스 꼬리재생 시간과 일치. 데이터그램은 `sendto` 이후 회수 불가이므로 latest-wins만으로는 못 막음 → 처방은 전송량↓(품질/FPS) 또는 무선 환경 개선(AP 채널 1/6/11 고정·20MHz 고정·거리 단축).
- **MCU 줄 인터리브 푸시 — 실측 실패로 기본 꺼짐**: JPEGDEC MCU 콜백에서 완성 줄을 즉시 LCD로 푸시해 SPI와 디코드를 겹치는 기법을 구현했으나 rt 불변(50~65ms, 품질 의존), 티어링은 악화. 원인: LovyanGFX `pushImage`는 트랜잭션 안에서도 매 호출 DMA 완료를 busy-wait → 공개 API로는 오버랩 불가. `RENDER_INTERLEAVE 0`으로 꺼두고 A/B 스위치·실측 기록은 코드에 보존.

### 📌 업그레이드 노트 (필독)
- **펌웨어 재업로드 필요**: `RENDER_INTERLEAVE=0`(원자적 blit 복귀) 빌드를 Arduino IDE에서 재업로드할 것. 업로드 전이라면 화면에 롤링 티어링이 남아 있을 수 있음.
- **호스트**: 새 기본값(품질 60/FPS 18)은 GUI 재시작 후 적용됨.
