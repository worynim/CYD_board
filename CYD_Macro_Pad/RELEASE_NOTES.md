## v1.1.1 (2026-08-25)

### 🐛 수정
- **세로→가로 복귀 불가 (펌웨어)**: 화면 회전 제어 패킷의 코드 검증이 `≤ 2`로 되어 있어 유효한 **코드 3(가로 정방향)** 을 거부했습니다. 세로 모드 진입 시 그 값이 NVS/`config.bin`에 저장되므로 재부팅해도 가로로 못 돌아오고, 플래시 삭제/재플래싱 없이는 복구가 불가능했던 치명적 버그입니다. 경계 조건을 `≤ 3`으로 수정했습니다.
- **회전 적용 타이밍 (펌웨어)**: 회전 제어 패킷 수신(Wi-Fi 콜백) 즉시 `setRotation`을 실행해 메인 루프의 LCD DMA 전송과 충돌할 수 있었습니다(화면 찢어짐/손상 위험). 이제 콜백은 플래그만 세우고 메인 루프에서 안전하게 적용합니다.
- **저장된 회전 값 복원 (펌웨어)**: 부팅 시 NVS·`config.bin`에서 회전을 읽는 코드도 동일한 `≤ 2` 경계 오류가 있어 저장된 "가로 정방향(3)"이 무시될 수 있었습니다. 함께 수정했습니다.
- **회전 변경 시 미저장 편집 유실 (호스트)**: 회전 콤보를 바꾸면 입력 중이던 라벨/액션 편집이 버려지고, 그 **빈 상태가 `macro_config.json`에 저장**될 수 있었습니다. 이제 탭 재구성 전에 현재 편집 상태를 먼저 수집해 반영합니다.
- **가져오기·디바이스 덤프 시 회전 불일치 (호스트)**: ⬆ 가져오기로 회전 값이 다른 설정을 읽으면 GUI 그리드가 따라가지 못했고, 🖥 디바이스에서 불러오기는 회전 선호를 가로로 초기화했습니다. 두 경로 모두 회전을 보존하고 그리드에 즉시 반영하도록 수정했습니다.
- **세로 모드 버튼 이미지 어긋남 (호스트)**: 버튼 이미지·한글 라벨 JPEG가 방향과 무관하게 고정 71×61로 렌더링되어, 세로 모드(버튼 72×63)에서 오른쪽 1px·아래 2px의 어두운 띠와 어긋난 둥근 모서리가 생겼습니다. 이제 현재 회전에 맞는 크기(가로 71×61 / 세로 72×63)로 렌더링합니다.
- **기타 (호스트)**: 회전 변경 시 페이지 카드를 두 번 다시 그리는 중복 렌더 제거, 언어 전환마다 예외만 삼키던 죽은 i18n 등록 항목 제거.

### 📌 배포·권한
- **펌웨어·호스트 동시 업데이트 필수**: 특히 **세로 모드 버튼 이미지 크기** 수정은 양쪽이 맞아야 정상 표시됩니다. 세로 모드를 사용한다면 Arduino IDE로 `CYD_Macro_Pad.ino`를 재업로드하세요 (기존 설정·버튼 이미지는 플래시에서 자동 복원).

## v1.1.0 (2026-08-25)

### ✨ 추가·개선
- **세로 모드(화면 회전) 지원**: 상태 카드에 **화면 회전** 콤보 추가 — 자동 감지 / 가로 정방향 / 가로 180도 / 세로 (Portrait) / 세로 180도. 선택 즉시 호스트 그리드가 재배치되고(세로 = 버튼 3×4), 제어 패킷으로 디바이스에도 바로 반영됩니다. "자동 감지"는 매크로패드에서는 가로 정방향과 동일하게 동작합니다.
- **회전 설정 저장·복원**: 회전 값은 호스트 설정(`macro_config.json`)과 디바이스 플래시(`config.bin`/NVS) 양쪽에 저장되어 어느 쪽을 재부팅해도 마지막 회전 상태가 유지됩니다. 호스트 시작 시 저장된 회전이 콤보에 반영되며, 새 디바이스 발견·설정 적용(Apply)·탭 순서 변경 시에도 함께 전송됩니다.
- **Wi-Fi 설정 화면은 항상 가로**: 디바이스의 Wi-Fi 재설정(스캔 목록·온스크린 키보드) 화면은 현재 회전과 무관하게 항상 가로 정방향으로 표시되어 입력이 어긋나지 않습니다.

### 📌 배포·권한
- **펌웨어·호스트 동시 업데이트 권장**: 회전은 새 제어 패킷(`MAGIC_CONTROL`)으로 전달됩니다. 하위 호환은 유지됩니다 — 구버전 펌웨어는 이 패킷을 무시하고 구버전 호스트는 전송하지 않습니다만, 회전 기능을 사용하려면 양쪽 모두 이 버전 이상이어야 합니다. 펌웨어 업데이트는 Arduino IDE로 `CYD_Macro_Pad.ino`를 재업로드하면 됩니다 (기존 설정·버튼 이미지는 플래시에서 자동 복원).

## v1.0.0 (2026-08-23)

### 🐛 수정
- **입력 액션 지연 / 10초 타임아웃**: `.app`으로 실행할 때 단축키·텍스트 액션이 매번 ~10초 지연 후 실행되던 문제를 수정했습니다. 원인은 PyInstaller **onefile** 입력 헬퍼가 실행마다 임시 폴더로 추출되며 macOS가 PyObjC dylib을 재검증해 시작에 ~9초가 걸린 것이며, **onedir** 전환으로 웜 실행 ~0.2초로 단축했습니다. 새 머신 최초 1회 콜드 스타트는 30초 타임아웃 + 앱 시작 시 백그라운드 프리워밍으로 처리됩니다.
- **리스너 크래시로 인한 액션 미동작**: UDP 리스너가 `sendto` 실패(예: ICMP "No route to host")를 로그로 남기는 중 **포맷 문자열 버그(TypeError)** 로 리스너 스레드가 죽어, 이후 모든 버튼 이벤트를 받지 못하던 문제를 수정했습니다. 단축키/텍스트가 "전혀 동작하지 않던" 직접 원인입니다.
- **접근성(손쉬운 사용) 권한 무효화**: PyInstaller 재빌드마다 ad-hoc 코드서명이 바뀌어 시스템이 기존에 등록한 권한을 새 빌드에 매칭하지 못하던 문제를 해결했습니다 (재등록 방법은 📌 참고).

### ✨ 추가·개선
- **접근성 자가진단**: 앱 시작 시 접근성 권한 상태를 디버그 로그(`~/Library/Application Support/CYD Macro Pad/listener_debug.log`)에 기록하고, 권한이 없으면 이벤트 로그에 경고를 표시합니다. 헬퍼가 `.app`의 권한을 상속받는지(`self`/`helper`)도 함께 확인합니다.
- **디버그 로그**: 리스너·접근성·자동동기화 상태를 `listener_debug.log`로 남겨 문제 진단을 돕습니다.

### 📌 배포·권한 (필독)
- **`.app` 재빌드 후 접근성 권한 재등록**: 재빌드하면 이전 등록이 무효화됩니다.
  1. 시스템 설정 → 개인정보 보호 및 보안 → **손쉬운 사용**
  2. 기존 **"CYD Macro Pad"** 항목을 **− (삭제)**
  3. **+ (추가)** → `Cmd+Shift+G`로 앱 경로 입력 → `CYD Macro Pad.app` 선택
  4. 토글 **ON** 후 앱 재시작
  - ⚠️ 토글을 껐다 켜는 것만으로는 이전 서명에 묶인 항목이 갱신되지 않으므로 **반드시 삭제 후 재추가**해야 합니다.
- 헬퍼가 `.app`의 권한을 상속하므로 등록은 `.app` 하나만 하면 됩니다.
