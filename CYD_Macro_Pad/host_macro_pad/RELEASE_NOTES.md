## v1.0.0 (2026-08-23)

### 🐛 수정
- **입력 액션 지연 / 10초 타임아웃**: `.app`으로 실행할 때 단축키·텍스트 액션이 매번 ~10초 지연 후 실행되던 문제를 수정했습니다. 원인은 PyInstaller **onefile** 입력 헬퍼가 실행마다 임시 폴더로 추출되며 macOS가 PyObjC dylib을 재검증해 시작에 ~9초가 걸린 것이며, **onedir** 전환으로 웜 실행 ~0.2초로 단축했습니다. 새 머신 최초 1회 콜드 스타트는 30초 타임아웃 + 앱 시작 시 백그라운드 프리워밍으로 처리됩니다.
- **리스너 크래시로 인한 액션 미동작**: UDP 리스너가 `sendto` 실패(예: ICMP "No route to host")를 로그로 남기는 중 **포맷 문자열 버그(TypeError)** 로 리스너 스레드가 죽어, 이후 모든 버튼 이벤트를 받지 못하던 문제를 수정했습니다. 단축키/텍스트가 "전혀 동작하지 않던" 직접 원인입니다.
- **접근성(손쉬운 사용) 권한 무효화**: PyInstaller 재빌드마다 ad-hoc 코드서명이 바뀌어 시스템이 기존에 등록한 권한을 새 빌드에 매칭하지 못하던 문제를 해결했습니다 (재등록 방법은 📌 참고).

### ✨ 추가·개선
- **접근성 자가진단**: 앱 시작 시 접근성 권한 상태를 디버그 로그(`~/Library/Application Support/CYD Macro Pad/listener_debug.log`)에 기록하고, 권한이 없으면 이벤트 로그에 경고를 표시합니다. 헬퍼가 `.app`의 권한을 상속받는지(`self`/`helper`)도 함께 확인합니다.
- **디버그 로그**: 리스너·접근성·자동동기화 상태를 `listener_debug.log`로 남겨 문제 진단을 돕습니다.

### 📌 배포·권한 (필독)
- **`.app` 재빌드 후 접근성 권한 재등록**: 재빌드하면 이전 등록이 무효화됩니다.
  1. 시스템 설정 → 개인정보 보호 및 보안 → **손쉬운 사용**
  2. 기존 **"CYD Macro Pad"** 항목을 **− (삭제)**
  3. **+ (추가)** → `Cmd+Shift+G`로 앱 경로 입력 → `CYD Macro Pad.app` 선택
  4. 토글 **ON** 후 앱 재시작
  - ⚠️ 토글을 껐다 켜는 것만으로는 이전 서명에 묶인 항목이 갱신되지 않으므로 **반드시 삭제 후 재추가**해야 합니다.
- 헬퍼가 `.app`의 권한을 상속하므로 등록은 `.app` 하나만 하면 됩니다.
